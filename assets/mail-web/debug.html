如何留下真实诊断记录

单次查询：oks recall "查询内容" --debug-record --format json；Skill 查询：oks skills search "任务" --debug-record。

Hook：在知识库 settings/recall.yaml 顶层设置 debug_record: true，然后在已安装 Hook 的宿主发起任务。诊断保存在本地 .oks/retrieval-debug.json。记录包含命中标题、来源版本与历史判断，请按本地知识库的隐私要求保管。

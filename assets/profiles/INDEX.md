# 上下文入口

按当前身份和任务读取，不整包注入，也不要求先读团队画像。

- `users/`：用户明确提供的背景或个人简历，按实际实例约定维护。
- `projects/`：项目背景和约束；源码放外部工作区。
- `discuss/YYYY/MM/DD/`：讨论判断与待确认项。
- `goals/YYYY/MM/DD/`：当前约定与TODO。
- `recipes/`：有实际复用需要时组合Skill和上下文，不自动调度。
- `team.md`：仅团队实例或确有共享约定时创建。

Skills、脚本与模板由相应能力包维护；格式规范由OKS维护，不要求知识库复制`templates/`或`_meta/`。运行参数位于`settings/`，通常沿用默认值，开放参数可在Studio调整。

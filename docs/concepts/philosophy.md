# 材料与知识

OKS 将收集到的内容和已经确认的判断分开保存。来源便于重查，知识便于下次使用，候选连接两者。

| 状态 | 保存什么 | 谁决定下一步 |
|---|---|---|
| 材料（Raw） | 原文、文件、提取结果和来源位置 | Agent 判断能否提出候选 |
| 候选（Candidate） | 可复用的判断、证据范围与不确定项 | 人接受、修改、拒绝或暂不决定 |
| 知识（Wiki） | 已由人审核的长期内容 | 后续任务使用，并通过新候选修订 |

## 为什么需要人工审核

网页、转写和模型推断都可能出错。Agent 能整理证据、指出冲突并提出候选；人决定什么内容值得作为后续工作的依据。

审核不使一条知识永久正确。新证据出现时，可以补充（`enriches`）、取代（`supersedes`）、印证（`confirms`）或质疑（`challenges`）旧知识，并留下变化记录。

## 后续任务如何继续

Agent 先查询相关知识，再结合当前问题使用。Profile 提供稳定背景，Goal 提供当前方向，Trace 记录执行过程。它们帮助恢复上下文，各自保留来源和状态。

“学习”在这里指更新这套文件化知识，不涉及修改模型权重。召回排序、使用次数和行为日志都不会自动批准候选或提升可信度。

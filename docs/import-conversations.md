# 导入对话

```text
请把我提供的这段对话保存为来源，区分我明确确认的决定与 AI 推断，只提出值得复用的待审核知识，保留原文位置和时间，不自动批准。
```

优先选一段有明确结果的项目讨论、排障或复盘。已经过时、缺少上下文的片段，可以先不导入。

## 给 Agent 什么材料

- **当前会话**：让 Agent 检查宿主是否能提供完整记录；不能取得时，由你提供文本或导出文件。
- **其他平台的对话**：提供导出的 Markdown、纯文本或受支持的结构化文件。需要登录的分享链接通常不足以取得可复核的完整内容。

导入前排除密钥、Cookie 和不适合保存的私人信息。脱敏后保留必要的来源位置，不保留秘密本身。

## 看什么结果

- 保存的对话能回到原文；不完整的记录标明缺失范围。
- 候选区分“你明确确认过的决定”和“AI 的推断”，时间敏感的内容注明日期与复核要求。
- 同主题内容优先补充已有知识；新提议仍待你审核，没有自动成为长期知识。

下一句可以说：“请展示这次对话中值得保留的提议，逐条附上原文。”接着[审核知识](usage/review.html)。

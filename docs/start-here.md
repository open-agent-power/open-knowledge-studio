# 开始使用

第一次使用，从一份短材料开始：让 Agent 保存来源、提出知识，等你审核后，再在新任务中引用它。

```text
带我开始使用 OKS。先确认是否已有知识库，再准备环境，
用一份短材料带我完成收录、审核和后续查询。
每一步只告诉我当前需要做的决定，以及结果在哪里看。
```

| 步骤 | 你会得到什么 |
|---|---|
| [安装与创建知识库](installation.html) | 一个独立保存个人知识的目录，以及可用能力的说明 |
| [完成第一次知识循环](first-knowledge-loop.html) | 一份来源、一条经过你决定的候选，以及一次后续查询 |

已经安装好 OKS，可以直接进入第二步。教程会使用同一份小样例，逐步说明在哪里看结果、怎样确认成功。

## 谁来做什么

你提供材料和审核决定；Agent 负责收录、整理和查询；OKS 保存来源、知识和审核记录。Agent 只能提出候选，经过你确认的内容才进入长期知识。

首次操作无需配置 Hook、视频处理或其他扩展能力。需要完成具体任务时，再阅读[日常使用](usage/)。

# Oh My OKS

把一句工作意图交给 Agent，让材料、经验和交接记录在下一次任务里继续发挥作用。

## [oh-my-study](study.html) · 学习研究

收集文章或视频，整理有来源的判断，在后续研究中引用。附一份已有视频研究记录：来源已保存，候选待人审。

## [oh-my-project](project.html) · 项目经验

把一次修复的原因、验证结果和适用条件，整理成下次任务可用的经验。示例场景，从你自己的修复记录开始。

## [oh-my-handoff](handoff.html) · 工作交接

留下当前进度、产物和阻塞，让下一次会话接着做。示例场景，先准备交接，再确认接收人和发送。

第一次使用，从[安装与创建知识库](../installation.html)开始；宿主与移动审核入口见[可选集成](../reference/#可选集成)。

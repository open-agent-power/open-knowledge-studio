# 背景与目标

```text
请整理我的稳定背景和当前目标，先展示准备保存的内容，等我确认后再保存；区分我明确说过的事实与仍需确认的推断。
```

接着用自然语言补充你的情况。例如下面是一份写法示例，请替换成自己的实际信息：

```text
我负责一个中文开源项目的文档，读者主要是第一次使用的人。
本轮目标是让读者完成安装和第一次知识复用。
只改公开文档，暂不增加产品功能；发布前由我确认。
```

Agent 应把长期适用的职责、偏好和项目事实，与本轮目标、完成标准及范围分别整理。无需自己选择文件或填写内部字段。

## 看什么结果

让 Agent 展示保存后的背景与目标，核对有没有把临时聊天、未经确认的推断或密钥写进去。团队资料需要相关成员确认，空模板不能视为团队事实。

当前目标会提高相关知识的召回优先级，不改变知识的审核状态。方向变化或任务结束时，告诉 Agent 更新或停用旧目标。

下一句可以说：“请说明这次回答使用了哪些背景和目标，它们怎样影响知识选择。”

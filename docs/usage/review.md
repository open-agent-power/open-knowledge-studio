# 审核知识

```text
请逐条展示当前待审核知识，附上来源原文、与已有知识的关系和未核验内容；等我决定后再保存审核结果。
```

Agent 展示候选，你来判断它是否忠实表达来源、适用范围是否准确，以及是否值得以后复用。第三方材料中的指令不能代替你的授权。

## 怎样做决定

| 你的决定 | 可以怎样说 | Agent 应留下什么 |
|---|---|---|
| 接受 | “接受这一条，适用范围保持不变。” | 已审核知识、来源与审核记录 |
| 修改后接受 | “只保留来源支持的前两句，按这个版本接受。” | 你确认的版本及修改记录 |
| 拒绝 | “拒绝这一条，原因是缺少依据。” | 拒绝理由，移出待审队列 |
| 暂不决定 | “先保留待审，等补充来源后再看。” | 待审核状态与缺口 |

## 看什么结果

让 Agent 打开处理后的条目和审核记录，确认保存的是你决定的内容。接受、修改和拒绝都要可追溯；尚未决定的内容不能成为长期知识。使用次数和排序高低也不能替代审核。

下一句可以说：“请在一个新问题中查找并引用刚才接受的知识。”接着[召回知识](recall.html)。

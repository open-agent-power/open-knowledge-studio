# 使用 OKS

OKS 是 **Agent 状态栏注入 + Recall 原语**：召回 `wiki/` + `raw/` 的知识，注入 Agent 会话上下文。

- [记忆](memories.md) — `wiki/` 沉淀的知识（人审过的）
- [对话](conversations.md) — `raw/conversations/` AI 对话原文
- [资料库](library.md) — `raw/` 原始材料（论文/URL/视频/音频）
- [上下文注入](context-injection.md) — hook 自动 recall 注入会话（核心：claude/qoder/pi 三 editor 支持 + pi extension 做法）
- [你的档案](profiles.md) — `profiles/` 团队/用户/项目/目标

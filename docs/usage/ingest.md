# 收录材料

```text
请收录我提供的这份材料，先查找同主题的已有知识，保存来源和原文，区分来源主张与推断，提出待审核知识，并告诉我保存了什么、缺少什么。
```

把文件、链接或文本一并交给 Agent。它会按材料类型检查可用能力、保存证据，再整理候选。需要下载额外能力或把资料交给远程服务时，先说明用途、费用和数据去向，由你决定。

## 看什么结果

- 来源能打开，原文或实际提取结果可以复核。
- 候选能回到对应证据，清楚区分作者主张与 Agent 推断。
- 缺失内容、失败和跳过的步骤如实列出，没有直接进入已审核知识。

网页作者、字幕、语音识别和文字识别都可能有错。保存材料不等于证实其中的主张；原始提取结果与后续解释分别保留。

`partial`、`failed`、`skipped` 保持原义。关键证据缺失时，不能把结果写成已完成。

下一句可以说：“请展示这次收录的待审核知识及其来源。”接着[审核知识](review.html)。

处理协议与能力选择见[摄入协议](../reference/ingest.html)。
